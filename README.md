# Vehicle Rental System

A Java-based Vehicle Rental System developed as a college mini-project.

## Technologies Used

- Java
- JSP
- Servlets
- JDBC
- MySQL
- Apache Tomcat
- HTML
- CSS
- Eclipse

## Features

### Customer
- User Registration
- User Login
- Browse Vehicles
- Rent Vehicle
- Return Vehicle
- View Rental History

### Admin
- Admin Login
- Add Vehicle
- Update Vehicle
- Delete Vehicle
- Manage Vehicle Status
- Automatically complete active rental when a rented vehicle is made available
